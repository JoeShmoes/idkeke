# **App Name**: ContextFlow

## Core Features:

- Smart Suggestions: Context-aware AI suggestions based on user activity across modules; adjusts tone via persona.
- Dashboard Overview: Responsive dashboard with KPI cards for Business, Finance, Wellness, Focus, and Creativity.
- Modular Structure: Modules for Business, Finance, Health, Creativity, Learning, Networking, Research, AI Room, and Tasks Room.
- Visualized Data: Interactive displays with KPI visualizations like graphs, timelines, and animated progress indicators.
- Decision Aid: Generative AI tool that presents pros and cons for decisions, using data from all modules.
- Tasks Room: Task management capabilities: To-do list with drag-and-drop priority ranking.
- Clear Navigation: Clean layout and minimalistic look and feel. Left vertical panel contains the main navigation, making it easy to switch modules. Navigation also features icons.

## Style Guidelines:

- Primary color: White (#FFFFFF) for a clean, modern look against the dark background.
- Background color: Gradient from dark gray (#1A1A1A) to black (#000000) for a sophisticated, high-tech feel.
- Accent color: Light Gray (#9b9b9b) to highlight the various on screen elements.
- Body and headline font: 'Inter' sans-serif for a neutral and modern aesthetic. This font will work for both headlines and body text.
- Glassy hover animations, parallax on cards, and glow effects to highlight key updates.
- Clean and minimalist layout. Easy to follow sections that contain important at a glance information.
- Clean, geometric icons. Enlarge the icon + slide label when hovered over in navigation.
